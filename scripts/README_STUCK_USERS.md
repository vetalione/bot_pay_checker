# 📨 РАЗОВАЯ РАССЫЛКА для застрявших пользователей

## 🎯 Назначение

Скрипт отправляет сообщение пользователям, которые застряли на этапах `start` или `video1`, предлагая им сразу перейти к оплате без просмотра остальных видео.

**Сообщение:**
```
Ладно, ладно, я поняла! 😁 Для самых нетерпеливых вот ссылка сразу на оплату продукта без прелюдий:

[💵 Оплатить рублями (4000 ₽)]
[💳 Иностранные карты (44€)]
[💴 Оплатить гривнами (2100 ₴)]
```

**✅ ОБНОВЛЕНО 5 ноября 2025:** Теперь использует новые кнопки с отслеживанием кликов!

## ⚠️ ВАЖНО

- ✅ Скрипт запускается **ОДИН РАЗ** вручную
- ✅ Отправляет только тем, кто застрял на `start` или `video1`
- ✅ Не трогает тех, кто уже оплатил (`hasPaid = true`)
- ✅ После выбора валюты пользователи попадают в обновленный флоу оплаты
- ✅ Клики на кнопки RUB/EUR/UAH **отслеживаются** в БД
- ❌ **НЕ добавляйте** этот скрипт в автоматические процессы!

## 🔍 Проверка перед запуском

Если хотите **просто посмотреть** сколько пользователей будет охвачено без отправки, выполните в Railway PostgreSQL:

```sql
-- Количество пользователей для рассылки
SELECT 
  "currentStep",
  COUNT(*) as count
FROM users 
WHERE "currentStep" IN ('start', 'video1') 
  AND "hasPaid" = false
GROUP BY "currentStep";

-- Детальный список (первые 20)
SELECT 
  "userId",
  username,
  "currentStep",
  "createdAt",
  "lastActivityAt"
FROM users 
WHERE "currentStep" IN ('start', 'video1') 
  AND "hasPaid" = false
ORDER BY "lastActivityAt" DESC
LIMIT 20;
```

## 🎯 Как это работает

1. **Подключается к БД** → находит пользователей с `currentStep = 'start'` или `'video1'` и `hasPaid = false`
2. **Отправляет сообщение** с кнопками выбора валюты
3. **Пользователь кликает** на кнопку (RUB или UAH)
4. **Обработчик `pay_rub`/`pay_uah`** срабатывает (уже настроен в `src/index.ts`)
5. **Пользователь получает** инструкции по оплате
6. **Далее** обычный флоу: ожидание квитанции → проверка → доступ к контенту

## ⚡ Особенности

### Защита от лимитов Telegram:

- Задержка **100ms** между сообщениями
- Telegram разрешает ~30 сообщений/секунду
- При 100ms задержке: **10 сообщений/секунду** (безопасно)

### Обработка ошибок:

- ✅ Продолжает работу даже если пользователь заблокировал бота
- ✅ Логирует все ошибки в конце
- ✅ Показывает прогресс в реальном времени

### Безопасность:

- ❌ Не отправляет тем, кто уже оплатил
- ❌ Не отправляет тем, кто прошел дальше `video1`
- ✅ Только разовая отправка (нет автоматизации)

## 🔧 Интеграция с основным ботом

**НЕ ТРЕБУЕТСЯ!** 

Скрипт использует **существующие обработчики** из `src/index.ts`:
- `bot.action('pay_rub', ...)` - обработчик RUB (строка ~420)
- `bot.action('pay_uah', ...)` - обработчик UAH (строка ~488)

После клика пользователь попадает в обычный флоу оплаты.
